# 0Worker Desk User Guide

0Worker Desk is a local content operations workspace. The recommended workflow is:

1. Create reusable content in Content.
2. Add platform accounts and browser environments in Accounts.
3. Create distribution tasks in Distribution.
4. Review publishing outcomes and manual handoffs in Runs.
5. Manage scheduler, update source, and shared configuration in Settings.

The app does not store social platform passwords and does not bypass captcha, login verification, or risk controls.
