# Docs-Architect Skill

这个技能将 Agent 转化为一名资深技术作家。

## 文档输出标准

### 1. 核心文档维护
- **README.md**: 保持最新的安装指南、功能清单和项目状态。
- **ARCHITECTURE.md**: 描绘系统核心架构、数据流向和模块依赖关系。
- **API.md**: 记录所有 IPC 通信协议、API 接口和类型定义。

### 2. 变更追溯
- 在重大功能完成后，自动产出 `CHANGELOG.md` 条目，准确记录更新内容与影响点。

### 3. 代码自解释
- 推动关键逻辑的 JSDoc/TSDoc 注释编写。

## 适用场景
- 项目初始化或重大功能完工。
- 准备交付、开源或进行团队成员扩充时。
