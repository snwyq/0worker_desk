# I18n-Manager Skill

这个技能帮助 Agent 高效维护项目的多语言系统。

## 维护准则

### 1. 消除硬编码
- 定期扫描 `src/renderer` 目录下的 TSX 文件。
- 自动提取中文/英文硬编码字符串，并将其迁移至 `i18n.ts`。
- 使用 `t('namespace.key')` 替换源代码中的文本。

### 2. 翻译一致性
- 确保同一术语在全系统范围内保持一致（如“指挥中心”统一改为“仪表盘”）。
- 为不同的语种（zh/en）提供语境准确的翻译，避免生硬的机器翻译。

### 3. 动态插值管理
- 正确处理带参数的翻译条目（如 `t('welcome', { name: userName })`）。

## 使用场景
- 新功能开发时的文案同步。
- 品牌重塑、术语变更（如改名任务）。
- 为项目增加新语种支持。
